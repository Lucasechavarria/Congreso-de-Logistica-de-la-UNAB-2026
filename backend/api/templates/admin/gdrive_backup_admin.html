💡 ¿Por qué se necesita el JSON de Google Service Account?

Aunque compartas una carpeta con "Cualquier persona con el enlace puede editar", la API de Google Drive no permite subidas anónimas desde un servidor. Para subir archivos por código se requiere una Cuenta de Servicio (Service Account) de Google Cloud, que actúa como un robot autorizado.

1
Entrá a Google Cloud Console y creá un proyecto gratis (ej: Congreso-UNaB).
2
En APIs y Servicios > Biblioteca, buscá Google Drive API y dale clic a Habilitar.
3
En IAM y Administración > Cuentas de Servicio, creá una cuenta (ej: bot-backup), creale una clave tipo JSON, descargala y pegá su contenido abajo.
4
En Google Drive, abrí tus 2 carpetas y compartilas con el email de esa Service Account (aparece en el JSON) con permiso de Editor.
