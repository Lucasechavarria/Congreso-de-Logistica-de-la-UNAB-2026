⚡ Paso a Paso: Subir a Google Drive con Apps Script (Sin Google Cloud)

✓ Solo 2 minutos

Como Google no permite subidas anónimas con el simple enlace de carpeta, este script en tu cuenta actúa como receptor autorizado y deposita el archivo ZIP en ambas carpetas automáticamente:

1
En tu navegador (con tu cuenta echavarrialucas1986@gmail.com), entrá a script.google.com y hacé clic en "Nuevo proyecto".
2
Borrá el código que aparece, copiá y pegá el código de abajo, y hacé clic en el ícono de Guardar (💾).
3
Arriba a la derecha hacé clic en Implementar > Nueva implementación. Seleccioná tipo: Aplicación web.
- En "Ejecutar como": Yo (tu cuenta).
- En "Quién tiene acceso": Cualquier usuario (Anyone).
4
Hacé clic en Implementar, autorizá los permisos y copiá la URL de la aplicación web (termina en /exec). Pegala en el campo "URL de Google Apps Script" abajo.
// Google Apps Script para recibir el respaldo y guardarlo en ambas carpetas de Drive
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var filename = data.filename || ("backup_congreso_" + Utilities.formatDate(new Date(), "GMT-3", "yyyyMMdd_HHmmss") + ".zip");
    var base64Data = data.base64;
    var carpetaPersonalId = data.carpeta_personal_id;
    var carpetaInstitucionalId = data.carpeta_institucional_id;
    
    var decoded = Utilities.base64Decode(base64Data);
    var blob = Utilities.newBlob(decoded, "application/zip", filename);
    
    var resultados = [];
    
    // 1. Guardar en Carpeta Personal
    if (carpetaPersonalId) {
      try {
        var folderPers = DriveApp.getFolderById(carpetaPersonalId);
        var filePers = folderPers.createFile(blob);
        resultados.push("✓ Guardado en Drive Personal (" + filePers.getName() + ")");
      } catch (errPers) {
        resultados.push("✗ Error en Drive Personal: " + errPers.toString());
      }
    }
    
    // 2. Guardar en Carpeta Institucional
    if (carpetaInstitucionalId) {
      try {
        var folderInst = DriveApp.getFolderById(carpetaInstitucionalId);
        var fileInst = folderInst.createFile(blob);
        resultados.push("✓ Guardado en Drive Institucional (" + fileInst.getName() + ")");
      } catch (errInst) {
        resultados.push("✗ Error en Drive Institucional: " + errInst.toString());
      }
    }
    
    return ContentService.createTextOutput(JSON.stringify({
      status: "ok",
      mensaje: resultados.join("\n")
    })).setMimeType(ContentService.MimeType.JSON);
    
  } catch (errGlobal) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      mensaje: errGlobal.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  return ContentService.createTextOutput("Webhook de Respaldo Congreso UNAB activo.");
}
